# Grounding Page Standard v1.6.1 – Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Das Bundle `trassd/contao-grounding-pages` auf Grounding Page Standard v1.6.1 heben. Dazu gehören eine zentrale Versionskonstante, der Abschnittstyp „Further Reading", Klassifikationsfelder und die JSON-LD-Spiegelung von Quellen, Further Reading und Klassifikation.

**Architecture:** Additive Erweiterung der bestehenden Pipeline Model → `GroundingPageComposer` → DTOs → Twig-Templates und `GroundingJsonLdBuilder`. Neue Abschnittstypen entstehen über die Enums `GroundingSectionType` und `SectionRowSchema`, aus denen DCA-Felder und Subpaletten automatisch abgeleitet werden. Die typabhängige Wahl der schema.org-Properties kapselt der reine Resolver `ClassificationPropertyMap`.

**Tech Stack:** PHP 8.3+, Contao 5.7, spatie/schema-org, Twig 3, PHPUnit 12, contao/test-case.

**Spec:** `docs/superpowers/specs/2026-10-08-standard-1-6-1-design.md` (im Bundle-Repo)

## Global Constraints

- Arbeitsverzeichnis für alle Befehle: `/var/www/html/packages/TrassdGroundingPages`, Branch `feature/standard-1.6.1`.
- Standardversion: `GroundingStandard::VERSION = '1.6.1'`, Spec-URL `https://groundingpage.com/spec/`.
- Alle neuen Felder und Properties sind optional. Leere Werte erzeugen weder Markup noch JSON-LD.
- Als URL gilt nur, was mit `http://` oder `https://` beginnt (`isUrl()`). Alles andere wird nie als `href` und nie als JSON-LD-URL ausgegeben.
- Neue DTO-Parameter kommen **ans Ende** der Konstruktoren und haben Defaults.
- Keine eigene Migration. Neue Spalten legt der Schema-Diff von `contao:migrate` an.
- Code-Kommentare auf Deutsch, so wie der bestehende Code. Bezeichner auf Englisch.
- **Commits:** Vor jedem Commit den User fragen. Commit-Nachricht = **eine Zeile, Englisch, Conventional Commit**, ohne Body und ohne Trailer.
- QA-Gate (Task 8): `composer all`, `vendor/bin/ecs check`, `vendor/bin/rector --dry-run`, alles grün.

## Review Focus

1. **Gefährliche URLs** (`javascript:alert(1)`, `ftp://…`, Leerzeichen) in Further Reading, `parentEntityUrl` und Beziehungs-URLs werden nie als Link gerendert und nie ins JSON-LD übernommen. Abgedeckt durch Tests in Task 3, 5 und 7.
2. **Alte Datensätze ohne neue Spalten** (Model-Property `null`): Der Composer liefert `''` bzw. `[]`, der Header rendert keine leeren `<dt>`, und das JSON-LD bleibt bis auf `category` und `citation` unverändert. Abgedeckt durch Tests in Task 4, 5 und 7.
3. **`customSchemaType = 'Organization'`** gilt als Custom-Typ. Dann greift der Fallback (`PropertyValue`), nicht `parentOrganization`. Abgedeckt durch Tests in Task 7.
4. **Further-Reading-Zeile nur mit Titel** (ohne URL) erscheint als Text im HTML und fehlt in `relatedLink`. **Gleiche URL in zwei Abschnitten** steht nur einmal in `relatedLink`. Abgedeckt durch Tests in Task 3 und 6.
5. **Halbe Beziehungszeilen** (Name ohne Beziehung oder umgekehrt, nur URL) werden verworfen. Abgedeckt durch Tests in Task 4.

```php
    /**
     * Liest ein rowWizard-Feld: trimmt alle Spalten und verwirft Zeilen, deren Werte
     * sämtlich leer sind.
     *
     * @return list<array<string, string>>
     */
    private function rowsOf(mixed $raw, string ...$keys): array
    {
        $out = [];

        foreach (StringUtil::deserialize($raw, true) as $row) {
            if (!\is_array($row)) {
                continue;
            }

            $values = [];

            foreach ($keys as $key) {
                $values[$key] = trim((string) ($row[$key] ?? ''));
            }

            if ('' === implode('', $values)) {
                continue;
            }

            $out[] = $values;
        }

        return $out;
    }

    /**
     * Beziehungen brauchen Beziehung und Name; die URL ist optional.
     *
     * @return list<array<string, string>>
     */
    private function relationships(mixed $raw): array
    {
        return array_values(array_filter(
            $this->rowsOf($raw, 'relation', 'name', 'url'),
            static fn (array $row): bool => '' !== $row['relation'] && '' !== $row['name'],
        ));
    }
```

```php
            $title = $source[$titleKey] ?? '';
            $url = $source[$urlKey] ?? '';
            $hasUrl = $this->isUrl($url);

            if ('' === $title && !$hasUrl) {
                continue;
            }

            $work = Schema::creativeWork()->name('' !== $title ? $title : $url);

            if ($hasUrl) {
                $work->url($url);
            }

            $citations[] = $work;
        }

        return $citations;
    }

    /**
     * Further Reading → relatedLink (schema.org erwartet URL-Strings).
     *
     * @return list<string>
     */
    private function buildRelatedLinks(GroundingPageDto $dto): array
    {
        $links = [];
        [, $urlKey] = SectionRowSchema::FurtherReading->columns();

        foreach ($this->collect($dto, static fn (GroundingSectionDto $section): array => $section->furtherReading) as $row) {
            $url = $row[$urlKey] ?? '';

            if ($this->isUrl($url)) {
                $links[] = $url;
            }
        }

        return array_values(array_unique($links));
    }
```

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages\JsonLd;

/*
 * Wählt für die Klassifikationsangaben (v1.6.1) die typgerechte schema.org-Property.
 * null bedeutet: Der Typ kennt keine passende Property, Ausgabe als PropertyValue in
 * additionalProperty. Eigene Typen (customSchemaType) fallen immer zurück, weil ihre
 * Hierarchie unbekannt ist.
 */
final class ClassificationPropertyMap
{
    private const GEOGRAPHIC_SCOPE = [
        'Organization' => 'areaServed',
        'Service' => 'areaServed',
        'CreativeWork' => 'spatialCoverage',
        'Dataset' => 'spatialCoverage',
    ];

    private const PARENT_ENTITY = [
        'Organization' => 'parentOrganization',
        'CreativeWork' => 'isPartOf',
        'Dataset' => 'isPartOf',
    ];

    /**
     * @return array{geographicScope: string|null, parentEntity: string|null}
     */
    public static function resolve(string $schemaType, bool $isCustomType): array
    {
        if ($isCustomType) {
            return ['geographicScope' => null, 'parentEntity' => null];
        }

        return [
            'geographicScope' => self::GEOGRAPHIC_SCOPE[$schemaType] ?? null,
            'parentEntity' => self::PARENT_ENTITY[$schemaType] ?? null,
        ];
    }
}
```
