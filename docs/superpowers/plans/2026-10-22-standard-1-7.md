# Grounding Page Standard v1.7 – Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Das Bundle `trassd/contao-grounding-pages` unterstützt Grounding Page Standard v1.7. Dazu gehören pflegbare Review-Felder (Reviewer-Typ, Reviewer-Name, Review-Datum), ein sichtbarer Review-Hinweis, `reviewedBy` und `lastReviewed` im JSON-LD und eine Standardversion, die pro Seite abgeleitet wird (1.7 mit Review, sonst 1.6.1).

**Architecture:** Additive Erweiterung der bestehenden Pipeline Model → `GroundingPageComposer` → `GroundingPageDto` → Twig-Templates und `GroundingJsonLdBuilder`. Ob eine Seite geprüft ist, entscheidet allein `GroundingPageDto::isReviewed()`. Footer, Review-Hinweis und JSON-LD fragen nur diese Methode ab. Die Speicher-Validierung liegt in der reinen Klasse `ReviewFieldsValidator`. Der DCA-Listener `ReviewFieldsListener` liest nur die Werte, übersetzt und wirft die Exception.

**Tech Stack:** PHP 8.3+, Contao 5.7, spatie/schema-org, Twig 3, PHPUnit 12, contao/test-case, Playwright (E2E im Root-Projekt).

**Spec:** `docs/superpowers/specs/2026-10-22-standard-1-7-design.md` (im Bundle-Repo)

## Global Constraints

- Arbeitsverzeichnis für alle Bundle-Befehle: `/var/www/html/packages/TrassdGroundingPages`, Branch `feature/standard-1.7`.
- Versionen: `GroundingStandard::BASE_VERSION = '1.6.1'`, `GroundingStandard::REVIEWED_VERSION = '1.7'`, `SPEC_URL = 'https://groundingpage.com/spec/'`. Die Konstante `VERSION` entfällt.
- Eine Seite gilt genau dann als geprüft, wenn `reviewerName !== ''` **und** `lastReviewed !== null`.
- `dateVerified` ist ab jetzt „Zuletzt aktualisiert“ (`dateModified`) und wird **nie** als Review-Datum verwendet.
- Ohne Review gibt es kein Review-Markup, keinen Platzhalter und keine Review-Properties.
- Datumswerte im DTO und im JSON-LD haben das Format `Y-m-d`.
- Neue DTO-Parameter kommen **ans Ende** des Konstruktors und haben Defaults.
- Keine eigene Migration. Neue Spalten legt der Schema-Diff von `contao:migrate` an.
- Enum-Cases im Stil von `GroundingEntityType` (`PERSON`, `ORGANIZATION`). Die Spec schreibt beispielhaft `Person`, gemeint ist derselbe Case.
- Code-Kommentare auf Deutsch, wie im bestehenden Code. Bezeichner auf Englisch.
- **Commits:** Vor jedem Commit den User fragen. Commit-Nachricht = **eine Zeile, Englisch, Conventional Commit**, ohne Body und ohne Trailer.
- QA-Gate (Task 8): `composer all`, `vendor/bin/ecs check`, `vendor/bin/rector --dry-run`, alles grün.

## Review Focus

1. **Reviewer-Name mit HTML** (`<b>X</b>`, `Müller & Söhne`) wird im Review-Hinweis escaped ausgegeben, obwohl die Übersetzung mit `|raw` gerendert wird. Im JSON-LD steht der Name unverändert. Test in Task 3.
2. **Halbe Review-Angaben aus Altbeständen oder Importen** (Name ohne Datum, Datum ohne Name, `lastReviewed = 0`): Die Seite gilt als ungeprüft, also kein Hinweis, kein `reviewedBy` und Footer v1.6.1. Tests in Task 1 und 6.
3. **Bearbeiten mehrerer Datensätze („Mehrere bearbeiten“)**: Die POST-Felder heißen dort `reviewerName_<id>`. Der Listener muss beide Schreibweisen lesen, sonst meldet er fälschlich „unvollständig“. Test in Task 5.
4. **Review-Datum heute** wird akzeptiert, **morgen** abgelehnt (Tagesvergleich, nicht Sekunden). Test in Task 5.
5. **Unbekannter `reviewerType`** in der Datenbank (`'team'`, leer) fällt auf `Person` zurück, statt einen ungültigen `@type` zu erzeugen. Test in Task 1 und 6.

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages\Enum;

/*
 * Wer das Fakten-Review verantwortet (Standard v1.7): eine Person oder eine
 * Organisation, beide gleichwertig konform.
 */
enum ReviewerType: string
{
    case PERSON = 'person';
    case ORGANIZATION = 'organization';

    public function schemaType(): string
    {
        return match ($this) {
            self::PERSON => 'Person',
            self::ORGANIZATION => 'Organization',
        };
    }

    public static function fromStringOrFallback(string $value): self
    {
        return self::tryFrom($value) ?? self::PERSON;
    }

    /**
     * @return list<string>
     */
    public static function values(): array
    {
        return array_column(self::cases(), 'value');
    }
}
```

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages;

/*
 * Einzige Quelle für die Versionen des Grounding Page Standards. Seit v1.7 nennt
 * jede Seite die Version, die sie tatsächlich erfüllt: ohne dokumentiertes
 * menschliches Review bleibt sie auf der Basisversion.
 */
final class GroundingStandard
{
    public const string BASE_VERSION = '1.6.1';

    public const string REVIEWED_VERSION = '1.7';

    public const string SPEC_URL = 'https://groundingpage.com/spec/';

    public static function versionFor(bool $reviewed): string
    {
        return $reviewed ? self::REVIEWED_VERSION : self::BASE_VERSION;
    }

    /**
     * Template-Daten für den Standard-Footer.
     *
     * @return array{version: string, specUrl: string}
     */
    public static function templateData(bool $reviewed = false): array
    {
        return ['version' => self::versionFor($reviewed), 'specUrl' => self::SPEC_URL];
    }
}
```

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages\Review;

/*
 * Prüfregeln für das menschliche Fakten-Review (Standard v1.7), ohne Framework-
 * Abhängigkeit: Name und Datum gibt es nur zusammen, und das Datum liegt nicht
 * in der Zukunft.
 */
final class ReviewFieldsValidator
{
    public const string ERROR_INCOMPLETE = 'reviewIncomplete';

    public const string ERROR_FUTURE = 'reviewInFuture';

    /**
     * @param string $date Timestamp, formatierter POST-Wert oder ''. Die
     *                     Zukunftsprüfung greift nur bei Timestamps.
     */
    public function validate(string $name, string $date, int $now): string|null
    {
        $date = trim($date);
        $hasName = '' !== trim($name);
        $hasDate = '' !== $date && '0' !== $date;

        if ($hasName !== $hasDate) {
            return self::ERROR_INCOMPLETE;
        }

        // Tagesvergleich: Ein Review von heute ist gültig, egal zu welcher Uhrzeit.
        if ($hasDate && ctype_digit($date) && date('Y-m-d', (int) $date) > date('Y-m-d', $now)) {
            return self::ERROR_FUTURE;
        }

        return null;
    }
}
```

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages\EventListener\DataContainer;

use Contao\CoreBundle\DependencyInjection\Attribute\AsCallback;
use Contao\DataContainer;
use Symfony\Component\HttpFoundation\RequestStack;
use Symfony\Contracts\Translation\TranslatorInterface;
use Trassd\Contao\GroundingPages\Review\ReviewFieldsValidator;

/*
 * Lehnt halbe Review-Angaben und Review-Daten in der Zukunft beim Speichern ab.
 * Das jeweils andere Feld kommt aus dem POST (auch als <feld>_<id> bei „Mehrere
 * bearbeiten“), sonst aus dem gespeicherten Datensatz.
 */
final class ReviewFieldsListener
{
    public function __construct(
        private readonly ReviewFieldsValidator $validator,
        private readonly RequestStack $requestStack,
        private readonly TranslatorInterface $translator,
    ) {
    }

    #[AsCallback(table: 'tl_grounding_page', target: 'fields.reviewerName.save')]
    public function onSaveReviewerName(mixed $value, DataContainer $dc): mixed
    {
        $this->assertValid((string) $value, $this->sibling('lastReviewed', $dc));

        return $value;
    }

    #[AsCallback(table: 'tl_grounding_page', target: 'fields.lastReviewed.save')]
    public function onSaveLastReviewed(mixed $value, DataContainer $dc): mixed
    {
        $this->assertValid($this->sibling('reviewerName', $dc), (string) ($value ?? ''));

        return $value;
    }

    private function assertValid(string $name, string $date): void
    {
        $error = $this->validator->validate($name, $date, time());

        if (null !== $error) {
            throw new \RuntimeException($this->translator->trans('tl_grounding_page.error.'.$error, [], 'contao_tl_grounding_page'));
        }
    }

    private function sibling(string $field, DataContainer $dc): string
    {
        $post = $this->requestStack->getCurrentRequest()?->request;

        foreach ([$field, $field.'_'.$dc->id] as $key) {
            if (null !== $post && $post->has($key)) {
                return trim((string) $post->get($key));
            }
        }

        return trim((string) ($dc->activeRecord?->{$field} ?? ''));
    }
}
```
