# Grounding Page Standard 2.0 – Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Das Bundle `trassd/contao-grounding-pages` unterstützt Grounding Page Standard 2.0: absolute, stabile Entity-`@id`s mit Referenzanker (RI-1/RI-2), geprüfte `sameAs`-URLs (RI-3), sichtbare offizielle Profile und Kennungen (RI-4/RI-5), `identifier` als `PropertyValue` (RI-E2) und eine Versionsangabe, die 2.0 nur nach expliziter Auswahl „Geprüft nach Standard 2.0“ und bestandenen RI-Prüfungen nennt.

**Architecture:** Neues Modul `src/Reference/` mit drei reinen bzw. schlanken Klassen: `SameAsPolicy` (RI-3-Regeln), `EntityIdentityResolver` (Seiten-URL, Entity-`@id`, Anker) und `ConformanceResolver` (1.6.1 / 1.7 / 2.0). Der Controller ermittelt die kanonische Seiten-URL, löst Identität und Konformität auf und gibt beides an `GroundingJsonLdBuilder` und an die Templates. Die Speicher-Validierung nutzt dieselbe `SameAsPolicy`; zur Laufzeit stuft `ConformanceResolver` bei Verstößen auf 1.7 herunter.

**Tech Stack:** PHP 8.3+, Contao 5.7, spatie/schema-org, Twig 3, PHPUnit 12, contao/test-case, symfony/string (AsciiSlugger), Doctrine DBAL, Playwright über Browserless (E2E im Root-Projekt).

**Spec:** `docs/superpowers/specs/2026-11-23-standard-2-0-design.md` (im Bundle-Repo)

`src/Reference/SameAsPolicy.php`:

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages\Reference;

/*
 * RI-3 (Standard 2.0): sameAs nur für offizielle Profile, Registereinträge und
 * Nachschlagewerk-Einträge zur Entität. Geprüft werden nur maschinell erkennbare
 * Ausschlüsse; ob ein Profil offiziell ist, beurteilt das menschliche Review.
 */
final class SameAsPolicy
{
    private const array DOI_ARXIV_HOSTS = ['doi.org', 'dx.doi.org', 'arxiv.org'];

    private const array SEARCH_QUERY_KEYS = ['q', 's', 'query', 'search'];

    /**
     * @param list<string> $ownHosts
     */
    public function check(string $url, array $ownHosts): SameAsViolation|null
    {
        if (!self::isAbsoluteHttpUrl($url)) {
            return SameAsViolation::NotHttp;
        }

        $host = (string) self::hostOf($url);

        foreach ($ownHosts as $ownHost) {
            $own = self::normaliseHost($ownHost);

            if ('' !== $own && ($host === $own || str_ends_with($host, '.'.$own))) {
                return SameAsViolation::OwnDomain;
            }
        }

        if (\in_array($host, self::DOI_ARXIV_HOSTS, true)) {
            return SameAsViolation::DoiOrArxiv;
        }

        if ($this->isSearchOrApi($url)) {
            return SameAsViolation::SearchOrApi;
        }

        if ('' !== (string) parse_url($url, PHP_URL_FRAGMENT)) {
            return SameAsViolation::SectionAnchor;
        }

        return null;
    }

    /**
     * @param list<string> $urls
     * @param list<string> $ownHosts
     *
     * @return array<string, SameAsViolation>
     */
    public function violations(array $urls, array $ownHosts): array
    {
        $out = [];

        foreach ($urls as $url) {
            $violation = $this->check($url, $ownHosts);

            if (null !== $violation) {
                $out[$url] = $violation;
            }
        }

        return $out;
    }

    public static function isAbsoluteHttpUrl(string $url): bool
    {
        if (false === filter_var($url, FILTER_VALIDATE_URL)) {
            return false;
        }

        return \in_array(strtolower((string) parse_url($url, PHP_URL_SCHEME)), ['http', 'https'], true);
    }

    public static function hostOf(string $url): string|null
    {
        $host = parse_url($url, PHP_URL_HOST);

        return \is_string($host) && '' !== $host ? self::normaliseHost($host) : null;
    }

    private static function normaliseHost(string $host): string
    {
        $host = strtolower(trim($host));

        return str_starts_with($host, 'www.') ? substr($host, 4) : $host;
    }

    private function isSearchOrApi(string $url): bool
    {
        $path = strtolower((string) parse_url($url, PHP_URL_PATH));

        if (1 === preg_match('#/(search|api)(/|$)#', $path) || str_contains($path, 'api.php') || str_contains($path, 'special:search')) {
            return true;
        }

        parse_str((string) parse_url($url, PHP_URL_QUERY), $query);

        return [] !== array_intersect(array_map(strval(...), array_keys($query)), self::SEARCH_QUERY_KEYS);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages;

/*
 * Einzige Quelle für die Versionen des Grounding Page Standards. Jede Seite nennt
 * die Version, die sie tatsächlich erfüllt. versionFor() kennt nur Review ja/nein
 * und liefert deshalb höchstens 1.7; 2.0 entscheidet der ConformanceResolver.
 */
final class GroundingStandard
{
    public const string BASE_VERSION = '1.6.1';

    public const string REVIEWED_VERSION = '1.7';

    public const string V2_VERSION = '2.0';

    public const string SPEC_URL = 'https://groundingpage.com/spec/';

    public static function versionFor(bool $reviewed): string
    {
        return $reviewed ? self::REVIEWED_VERSION : self::BASE_VERSION;
    }

    /**
     * Template-Daten für den Standard-Footer. Ohne aufgelöste Version gilt
     * versionFor(), ein überschriebenes Template behauptet also nie fälschlich 2.0.
     *
     * @return array{version: string, specUrl: string}
     */
    public static function templateData(bool $reviewed = false, string|null $version = null): array
    {
        return [
            'version' => null !== $version && '' !== $version ? $version : self::versionFor($reviewed),
            'specUrl' => self::SPEC_URL,
        ];
    }
}
```

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages\Reference;

use Trassd\Contao\GroundingPages\Dto\GroundingPageDto;

/*
 * Leitet die Identität ab: explizites entityId gewinnt; sonst Anker-URL (Feld
 * anchorUrl, ersatzweise die Seiten-URL) plus Typ-Fragment. Der Automatismus ist
 * nur stabil, solange der Datensatz auf genau einer Seite in einer Sprache steht.
 */
final class EntityIdentityResolver
{
    public function resolve(GroundingPageDto $dto, string $pageUrl): EntityIdentity
    {
        $pageUrl = self::stripQueryAndFragment($pageUrl);
        $anchorUrl = '' !== $dto->anchorUrl ? $dto->anchorUrl : $pageUrl;
        $entityId = '' !== $dto->entityId
            ? $dto->entityId
            : self::stripQueryAndFragment($anchorUrl).self::fragmentFor($dto->schemaType);

        return new EntityIdentity(
            pageUrl: $pageUrl,
            entityId: $entityId,
            anchorUrl: $anchorUrl,
            isAnchor: self::stripQueryAndFragment($anchorUrl) === $pageUrl,
        );
    }

    public static function fragmentFor(string $schemaType): string
    {
        $type = strtolower(trim($schemaType));

        return '#'.('' === $type || 'thing' === $type ? 'entity' : preg_replace('/[^a-z0-9]/', '', $type));
    }

    public static function stripQueryAndFragment(string $url): string
    {
        return (string) preg_replace('/[?#].*$/', '', $url);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages\Reference;

use Contao\CoreBundle\Monolog\ContaoContext;
use Psr\Log\LoggerInterface;
use Symfony\Component\DependencyInjection\Attribute\Autowire;
use Trassd\Contao\GroundingPages\Dto\GroundingPageDto;
use Trassd\Contao\GroundingPages\GroundingStandard;

/*
 * Entscheidet, welche Standardversion eine Seite nennt. 2.0 nur nach explizitem
 * 2.0-Review und bestandenen Laufzeitprüfungen; sonst höchstens 1.7, damit nie
 * fälschlich 2.0 behauptet wird (Standard 2.0, P-10).
 */
final readonly class ConformanceResolver
{
    public function __construct(
        private SameAsPolicy $policy,
        #[Autowire(service: 'monolog.logger.contao.error')]
        private LoggerInterface|null $logger = null,
    ) {
    }

    public function resolve(GroundingPageDto $dto, EntityIdentity $identity): ConformanceResult
    {
        if (!$dto->isReviewed()) {
            return new ConformanceResult(GroundingStandard::BASE_VERSION);
        }

        if (GroundingStandard::V2_VERSION !== $dto->reviewStandard) {
            return new ConformanceResult(GroundingStandard::REVIEWED_VERSION);
        }

        $violations = [];

        if (!SameAsPolicy::isAbsoluteHttpUrl($identity->entityId)) {
            $violations[] = 'entityId';
        }

        $ownHosts = array_values(array_filter(array_map(
            SameAsPolicy::hostOf(...),
            [$identity->pageUrl, $identity->entityId, $identity->anchorUrl],
        )));

        foreach ($this->policy->violations($dto->sameAsUrls(), $ownHosts) as $url => $violation) {
            $violations[] = 'sameAs:'.$violation->value.':'.$url;
        }

        if ([] === $violations) {
            return new ConformanceResult(GroundingStandard::V2_VERSION);
        }

        $this->logger?->warning(
            \sprintf('Grounding Page "%s" (%s) is reviewed against standard 2.0 but fails reference integrity: %s. Stating 1.7.', $dto->name, $identity->pageUrl, implode(', ', $violations)),
            ['contao' => new ContaoContext(__METHOD__, ContaoContext::ERROR)],
        );

        return new ConformanceResult(GroundingStandard::REVIEWED_VERSION, $violations);
    }
}
```

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages\Controller\ContentElement;

use Contao\ContentModel;
use Contao\CoreBundle\Controller\ContentElement\AbstractContentElementController;
use Contao\CoreBundle\DependencyInjection\Attribute\AsContentElement;
use Contao\CoreBundle\Framework\ContaoFramework;
use Contao\CoreBundle\Routing\ContentUrlGenerator;
use Contao\CoreBundle\Twig\FragmentTemplate;
use Contao\GroundingPageModel;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Generator\UrlGeneratorInterface;
use Trassd\Contao\GroundingPages\Composer\GroundingPageComposer;
use Trassd\Contao\GroundingPages\JsonLd\GroundingJsonLdBuilder;
use Trassd\Contao\GroundingPages\Reference\ConformanceResolver;
use Trassd\Contao\GroundingPages\Reference\EntityIdentityResolver;

#[AsContentElement(type: 'grounding_page', category: 'includes', template: 'content_element/grounding_page')]
class GroundingPageController extends AbstractContentElementController
{
    public function __construct(
        private readonly ContaoFramework $framework,
        private readonly GroundingPageComposer $composer,
        private readonly GroundingJsonLdBuilder $jsonLdBuilder,
        private readonly EntityIdentityResolver $identityResolver,
        private readonly ConformanceResolver $conformanceResolver,
        private readonly ContentUrlGenerator $urlGenerator,
    ) {
    }

    protected function getResponse(FragmentTemplate $template, ContentModel $model, Request $request): Response
    {
        $page = $this->framework->getAdapter(GroundingPageModel::class)->findPublishedById((int) $model->groundingPage);

        if (!$page instanceof GroundingPageModel) {
            return new Response();
        }

        $dto = $this->composer->compose($page);
        $identity = $this->identityResolver->resolve($dto, $this->pageUrl($request));
        $conformance = $this->conformanceResolver->resolve($dto, $identity);

        // Standard 2.0: Der Kasten „Hinweis für menschliche Leser“ wird nicht mehr empfohlen.
        if ($conformance->isV2()) {
            $dto = $dto->withHumanNotice(false);
        }

        $this->jsonLdBuilder->addToResponseContext($dto, $identity);

        $template->set('grounding', $dto);
        $template->set('identity', $identity);
        $template->set('conformance', $conformance);

        return $template->getResponse();
    }

    /**
     * Kanonische absolute URL der aktuellen Seite, ohne Query-String (RI-1).
     */
    protected function pageUrl(Request $request): string
    {
        $pageModel = isset($this->container) ? $this->getPageModel() : null;

        if (null !== $pageModel) {
            try {
                return EntityIdentityResolver::stripQueryAndFragment(
                    $this->urlGenerator->generate($pageModel, [], UrlGeneratorInterface::ABSOLUTE_URL),
                );
            } catch (\Throwable) {
                // Fallback unten, z. B. für Seiten ohne routbare URL.
            }
        }

        return $request->getSchemeAndHttpHost().$request->getPathInfo();
    }
}
```

Hinweis: `$this->container` ist in `AbstractController` eine typisierte Property; `isset()` ist im Unit-Test ohne `setContainer()` false. Falls PHPStan sich beschwert, `getPageModel()` in `try { … } catch (\Error) { … }` kapseln statt `isset`.

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages\EventListener\DataContainer;

use Contao\DataContainer;
use Symfony\Component\HttpFoundation\RequestStack;

/*
 * Liest ein Geschwisterfeld beim Speichern: erst POST (auch <feld>_<id> bei
 * „Mehrere bearbeiten“), sonst den gespeicherten Datensatz.
 */
final readonly class DcaSiblingReader
{
    public function __construct(private RequestStack $requestStack)
    {
    }

    public function read(string $field, DataContainer $dc): string
    {
        $post = $this->requestStack->getCurrentRequest()?->request;

        foreach ([$field, $field.'_'.$dc->id] as $key) {
            if (null !== $post && $post->has($key)) {
                return trim((string) $post->get($key));
            }
        }

        $record = $dc->getCurrentRecord();

        return trim((string) ($record[$field] ?? ''));
    }
}
```

```php
<?php

declare(strict_types=1);

namespace Trassd\Contao\GroundingPages\EventListener\DataContainer;

use Contao\CoreBundle\DependencyInjection\Attribute\AsCallback;
use Contao\CoreBundle\Framework\ContaoFramework;
use Contao\DataContainer;
use Contao\Message;
use Contao\StringUtil;
use Doctrine\DBAL\Connection;
use Trassd\Contao\GroundingPages\GroundingStandard;
use Trassd\Contao\GroundingPages\Reference\OwnHostsProvider;
use Trassd\Contao\GroundingPages\Reference\SameAsPolicy;
use Trassd\Contao\GroundingPages\Review\ReviewFieldsValidator;
use Symfony\Contracts\Translation\TranslatorInterface;

/*
 * Standard 2.0 beim Speichern: absolute Identifier, „Geprüft nach“ nur mit Review,
 * sameAs nach RI-3. Bei „Geprüft nach 2.0“ blockiert ein Verstoß, sonst nur Hinweis.
 */
final readonly class ReferenceFieldsListener
{
    public function __construct(
        private SameAsPolicy $policy,
        private ReviewFieldsValidator $validator,
        private DcaSiblingReader $siblings,
        private OwnHostsProvider $ownHosts,
        private TranslatorInterface $translator,
        private ContaoFramework $framework,
        private Connection|null $connection = null,
    ) {
    }

    #[AsCallback(table: 'tl_grounding_page', target: 'fields.reviewStandard.save')]
    public function onSaveReviewStandard(mixed $value, DataContainer $dc): mixed
    {
        $error = $this->validator->validateStandard(
            (string) $value,
            $this->siblings->read('reviewerName', $dc),
            $this->siblings->read('lastReviewed', $dc),
        );

        if (null !== $error) {
            throw new \RuntimeException($this->trans('error.'.$error));
        }

        return $value;
    }

    #[AsCallback(table: 'tl_grounding_page', target: 'fields.entityId.save')]
    #[AsCallback(table: 'tl_grounding_page', target: 'fields.anchorUrl.save')]
    public function onSaveAbsoluteUrl(mixed $value, DataContainer $dc): mixed
    {
        $url = trim((string) $value);

        if ('' !== $url && !SameAsPolicy::isAbsoluteHttpUrl($url)) {
            throw new \RuntimeException($this->trans('error.notAbsoluteUrl', [$url]));
        }

        return $value;
    }

    #[AsCallback(table: 'tl_grounding_page', target: 'fields.sameAs.save')]
    public function onSaveSameAs(mixed $value, DataContainer $dc): mixed
    {
        $urls = array_values(array_filter(array_map(
            static fn (mixed $row): string => trim((string) (\is_array($row) ? reset($row) : $row)),
            StringUtil::deserialize($value, true),
        )));

        $this->check(
            $urls,
            GroundingStandard::V2_VERSION === $this->siblings->read('reviewStandard', $dc),
            $this->siblings->read('entityId', $dc),
            $this->siblings->read('anchorUrl', $dc),
        );

        return $value;
    }

    #[AsCallback(table: 'tl_grounding_section', target: 'fields.identifiers.save')]
    public function onSaveSectionIdentifiers(mixed $value, DataContainer $dc): mixed
    {
        $urls = [];

        foreach (StringUtil::deserialize($value, true) as $row) {
            $candidate = \is_array($row) ? trim((string) ($row['value'] ?? '')) : '';

            if (str_starts_with($candidate, 'http://') || str_starts_with($candidate, 'https://')) {
                $urls[] = $candidate;
            }
        }

        $pid = (int) ($dc->getCurrentRecord()['pid'] ?? 0);
        $parent = $pid > 0 && null !== $this->connection
            ? $this->connection->fetchAssociative('SELECT reviewStandard, entityId, anchorUrl FROM tl_grounding_page WHERE id = ?', [$pid])
            : false;

        $this->check(
            $urls,
            GroundingStandard::V2_VERSION === ($parent['reviewStandard'] ?? ''),
            (string) ($parent['entityId'] ?? ''),
            (string) ($parent['anchorUrl'] ?? ''),
        );

        return $value;
    }

    /**
     * @param list<string> $urls
     */
    private function check(array $urls, bool $blocking, string $entityId, string $anchorUrl): void
    {
        $violations = $this->policy->violations($urls, $this->ownHosts->hosts($entityId, $anchorUrl));

        if ([] === $violations) {
            return;
        }

        $messages = [];

        foreach ($violations as $url => $violation) {
            $messages[] = $this->translator->trans($violation->translationKey(), [$url], 'contao_tl_grounding_page');
        }

        if ($blocking) {
            throw new \RuntimeException(implode(' ', $messages));
        }

        $message = $this->framework->getAdapter(Message::class);

        foreach ($messages as $text) {
            $message->addInfo($text);
        }
    }

    /**
     * @param list<string> $params
     */
    private function trans(string $key, array $params = []): string
    {
        return $this->translator->trans('tl_grounding_page.'.$key, $params, 'contao_tl_grounding_page');
    }
}
```
